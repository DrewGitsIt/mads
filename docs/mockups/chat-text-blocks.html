(b)'s join rule (revised 2026-10-20 after the provider survey): adjacent visible text items are joined before markdown parsing, whether they share a message id (claude blocks) or not (codex items, goose/hermes model calls). If block 1 already ends with a newline, they're joined as is (R4B stays one tight list); otherwise a blank line goes between them (R4A, R4C, R4D become separate paragraphs). A tool call, or a thinking block with text, still ends the bubble, exactly as today. The same rule runs on the live frames and on the stored rows, so turn end changes nothing.
