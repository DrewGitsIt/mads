Session commands: /usage, /new*, /export

A discussion mockup for the first harness-agnostic command pass. Each section has the UI on top and the open questions below it. These cards use the command-framework card kit (docs/mockups/command-framework.html): UI chrome above the composer that is never written to the transcript.

1 /usage: one card for health and usage aliases: /status, /context

/usage
No header or footer. Esc or clicking away closes the card. There's no "copy as JSON". Cost became a billing-mode switch: one spend section shows whichever signal matches how the session is billed, and is left out when there's none. Each layout is built to handle 2 to 4 sections without stretching.

  "health":  { "state", "since", "process_started_at", "last_event_at", "harness", "version", "preflight_ok" },  // always (mads)

  "tokens":  { "input", "output", "cache_read"?, "cache_write"?, "turns" },                       // when reported
  "billing": { "mode": "plan" | "usage" | "unknown" },                                           // decides the 4th panel
  "limits":  [ { "id", "label", "used_pct", "resets_at", "scope": "account" } ]?,               // mode = plan

}
