Task Graph — at-a-glance status encoding

Principle: state should land before reading. Four redundant channels, each reserved for one job: luminance (done work recedes, open work is bright), motion (only the thing running now moves), shape (each state has a distinct glyph silhouette — works in grayscale and for CVD), and fill/texture (blocked gets the danger fill + hatched spine + stop-octagon; never color alone). The status tag text stays on hover/detail — the card itself is the tag now.

The five treatments

Done — recedes55% opacity, muted title, filled ✓ disc. Finished work stops competing for attention; the graph's brightness map is the remaining work.
In progress — the only loud oneInfo fill + glow + spinning arc + stage pips (architect→…→verify) with the current stage lit and named. Motion is reserved for "now" — one moving card per slot, so your eye finds it instantly.
Ready — crispFull-contrast neutral card, hollow ring ("empty, waiting to be filled"). The default visual weight.
Blocked — interruptsDanger fill, hatched left spine (texture survives grayscale), stop-octagon glyph, and the reason inline on the card — blocked cards answer "why" without a click.
Draft — ghostDashed border, transparent fill: visibly not yet real.

Edges inherit state: gray-faded out of done nodes, animated dashes out of the running node (the amendment's garnish, now earning its keep), danger-tinted into blocked ones. The summary strip doubles as a filter: hover a chip to spotlight that state, click to isolate it — the counts give the 1000-ft answer ("14 · 1 · 3 · 1") before the canvas gives the spatial one. Reduced-motion swaps the spinner and dash animation for static equivalents.
