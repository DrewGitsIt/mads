Changes tab — diff real estate on a 13" laptop

Each frame is drawn at the real fullscreen viewport of Drew's 13" (1466 × 880 CSS px; scroll sideways if your window is narrower). The orange tag on each frame shows the diff pane's live width. Monaco's side-by-side view needs more than 900px.

  • In every option: long lines wrap, one line-number gutter, soft palette tints, new and deleted files shown as plain code with a thin edge bar, and the Inline / Side by side toggle always works.
  • B: hide the list with \ or the ⇤ button, drag its edge to resize, and the turn strip folds to one line while a file is open (click the mini bars to unfold it).
  • C: the list sits above the diff in three columns of one-line rows, the diff gets the full width, and ‹ › in the diff header steps through files.
  • Focus (Drew's idea): the ⤢ button slides the Changes tab left over the session sidebar; the icon rail stays. Try it in either frame. Esc or ⤡ brings the sidebar back.

Today for reference: list 440px, unwrapped, solid vs-dark tints, toggle forced to inline

B — collapsible list + folded strip recommended base

  • List open, sidebar shown: the list defaults to 340px (the old Files tab's width), so the diff gets ~770px. Lines wrap, so Inline reads well. Side by side works but is tight.
  • List hidden (\): the diff gets ~1110px, enough for Side by side. j/k or ‹ › in the diff header still step through files, so hiding the list doesn't strand you.
  • Focus on: the list and diff both fit, with ~1080px for the diff. On your laptop this is the most comfortable state.
  • The list width and hidden state are remembered (a view preference, so localStorage, like the rail's Done list). The folded strip unfolds on click and refolds once you pick a file.

C — stacked list above, diff below at full width

  • The diff is always full width, ~1110px with the sidebar shown or ~1420px with Focus on, so Side by side always fits.
  • Cost: height. On an 880px screen the list gets ~8–10 rows of three columns before the diff has too little room. Three columns of names don't read as a ranked list, and the Folder tree and Turn grouping, the core of the gold mockup, get cramped. Drag the divider to trade list rows for diff lines.
  • It breaks from the gold layout and from the rail, which both read as a ranked list. I'd only use it as an automatic fallback below some width, not as the default.

Recommendation

  • B with Focus, and only B: one layout, no breakpoint switching. Focus covers small screens; hiding the list covers reading one big file.
  • When Focus applies: I'd make it automatic whenever the window is narrower than ~1600px while the Changes tab has a file open, plus a ⤢ button anywhere. Leaving the Changes tab, or Esc with nothing else open, brings the sidebar back. The alternative is manual only. Automatic sliding could feel jumpy when you tab in, so the slide is short (220ms) and the icon rail stays put to keep you oriented.
  • Risk: the sidebar shows other sessions turning Attn. While Focus is on, the icon rail's S gets a dot when any session needs attention, so nothing is hidden silently.
