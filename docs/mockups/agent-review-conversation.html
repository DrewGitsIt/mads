A review of everything the session's agent changed, by a separate, read-only reviewer. It's started with /review or the Changes tab's Agent Review button (same job), can take several minutes on local inference, and runs while the main agent keeps working. What every option shares

  • /review is a two-level command (like /new*): the second level is the scope, and the rows show what each scope covers before you pick.
  • The footer of the menu names the reviewer and limit, since that is the one thing you can't see anywhere else before it starts.
  • Nothing goes to the main agent. The command itself is UI chrome; what it leaves in the transcript is the background item below.
  • A second /review while one runs doesn't start another: it scrolls to (or flashes) the running one.
