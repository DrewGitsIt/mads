Compare to
  • Turn strip. Each turn's whole column is the click target; a turn with no file changes keeps a flat stub, but its column is still clickable and still shows its prompt. Hovering previews a turn's prompt on the context line, and clicking pins it. Shift-click selects a range; the arrows step one turn at a time. In Tier, Folder and Commit grouping the strip filters the list. In Turn grouping it navigates: the turn in view lights up blue, and clicking scrolls to that turn.
  • Long sessions. Past about 30 turns, the columns narrow down to an 8px minimum and the strip scrolls horizontally, keeping the selected turn in view. The arrows and the context line work the same at any length.
  • Rows carry only the new-since-you-looked dot, the A/M/D badge, the name, +/− counts and a size bar. Committed state is shown by the Commit grouping and by the diff header's “committed in …” link.
  • Folder is a standard tree: compact folders, alphabetical order, and a file count and +/− total on every folder. Folders holding only generated or scratch files start collapsed and dimmed. Files outside the session folder get their own root.
  • Inside every group (a turn, a commit, an intent) files sort by tier first and size second, so source leads and generated and scratch sink and dim. Tier stays the backbone even when it is not the grouping.
  • Commit grouping puts Uncommitted first, then commits newest first. A file that is in two commits appears under each one, and each entry shows that commit's diff, which is what today's CommitList already does.

Context rail · Changes

  • Top to bottom, as you sketched: a Changes header with the file count, the tier dropdown, the ‹ turn › selector, the files, and a link to the Changes tab.
  • The dropdown shows a count for each tier and has an “All files” entry. Its default is Source, because that's what you want at a glance.
  • The turn selector starts on “All turns”. The arrows skip turns that changed nothing in the chosen tier, so with Source selected, stepping goes 2 → 3 → 4 → 5 → 6… and never lands on an empty list. Below it, the turn's prompt is clamped to two lines, using the same text the tab's context line shows.
  • Files are sorted by size, with the filename first and the folder underneath, as the rail has today. Clicking a file opens the Changes tab on that file with the same tier and turn applied.
  • The footer link carries the current tier and turn to the Changes tab. Scratch can be chosen here, but deleting happens only in the tab.
