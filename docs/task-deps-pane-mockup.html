Why this shape

Checkbox ≠ membershipA checkbox beside a task title reads as done/not-done everywhere else in the product. Membership is now shown by presence in the list; status is shown by the graph's own glyphs — one vocabulary, twice deployed.
Signal over inventoryThe old wall listed every task in the session (50 rows on Maintenance) to encode "no dependencies". The new empty state says it in six words, and the summary line + ribbon answer "how close is this to unblocked?" at a glance.
Same rules, better doorThe picker keeps the existing cycle heads-up (server check stays authoritative on save) and disables duplicates inline. Rows click through to the dependency's own pane; remove is the hover ×, matching the canvas's edge-delete.
