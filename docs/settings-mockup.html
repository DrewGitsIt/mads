New sessions

Where sessions start
Start in
A workspace starts in its primary repo. Choosing one clears the other, the same way the Launchpad does.
Workspace
e2e workspace
Folder
Sessions start in ~/repo/mads, the folder mads was launched from. Choose Folder to pin a different one. The Launchpad can always pick a folder for a single session.
Subagents
Show subagents in the session list
They appear under their session while they work. The conversation always shows them.
Hide finished ones after
Counted from when a subagent finishes. A running one never fades.
Commits
Write commit messages for me
Commit in the session's status line skips the dialog: the Fast Model writes the message and commits all of this session's files. You can undo from the result.
