Profiles, rethought — switch fast, see what changed

A profile is a named bundle of settings overrides. Today it can't hold settings (create ships an empty bundle), nothing records which one is active, and activation is invisible. This mockup fixes all three: profiles live in General where you already are, switching previews its diff before it applies, and the editor makes "override vs. inherit" explicit per field. Interactive — click the profile cards.
