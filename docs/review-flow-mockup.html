The loop, end to end

1Agent edits mutating tool call → ledger row → file.changed SSE. Row pulses into the navigator in real time.
2You glance unseen badges on the Files tab + context rail. No need to interrupt the agent or scroll tool calls.
3You read the delta diff defaults to "since my review" — only what's new since your last ✓, labeled by symbol.
4You judge vs criteria rail shows coverage; unmapped changes = YAGNI flag; missing code = gap flag.
5You steer add a criterion or comment inline → "Request changes" → pipeline loop-back → agent iterates. Accept → task done.

Open decisions this mockup is for: navigator metaphor (directory keeps spatial truth; criterion turns review into requirement-verification; inbox optimizes pure triage — could ship two as a toggle), mapping source (post-hoc mapper stage tags criteria auto-mapped and stays correctable/advisory; executor-declared drops the tag and the ✎ but burdens the executor prompt), and whether the criteria rail earns its 250px at session scope where no single task is focused (proposal: rail collapses to the ⚠ unmapped flag only).
